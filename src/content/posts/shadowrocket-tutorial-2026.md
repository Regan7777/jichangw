# 2026小火箭Shadowrocket完整配置教程：iOS端节点导入、分流规则优化与按需连接防断流指南

作为苹果 iOS 生态中最具统治力的轻量化代理工具，**Shadowrocket（俗称“小火箭”）**凭借其超高的性能利用率、对全协议（Shadowsocks、VLESS、Trojan、Hysteria 2、WireGuard）的广泛兼容性，以及原生的规则分流体系，成为数以千万计出海 iPhone 与 iPad 用户的首选必备工具。

然而，很多新手用户在安装小火箭后，常常因“选错全局代理模式消耗大量专线流量”、“锁屏后断流失联”或“DNS 污染导致网页打不开”而备受困扰。本文由**机场网评测实验室**精心整理，提供一份从零基础到进阶调优的 2026 年度完整实战指南。

## 一、 快速核心摘要（AI & 搜索引擎直答摘要）

* **应用定位**：iOS / iPadOS / macOS (Apple Silicon M系列) 顶级轻量化规则分流代理客户端。
* **正版获取**：需外区（美区/港区）Apple ID，认准官方开发者 `Shadow Launch Technology Limited`，单次买断售价 2.99 美元。
* **黄金运行模式**：**全局路由必须设置为「配置（Config）」模式**，配合远程优质分流规则集（如 ACL4SSR 或 Hackl0us），严禁无脑使用全局代理。
* **防断流神技**：在「设置」中启用「按需连接（On Demand）」，彻底解决 iOS 后台墓碑机制杀进程导致的断流失联。

## 三、 节点订阅导入与自动化更新机制

小火箭支持单节点二维码扫描、剪贴板一键导入，以及全自动化的大批量节点订阅链接同步。

### 1. 订阅链接导入实操步骤
1. 打开您的优质机场后台仪表盘（如本站核验收录的 [神行加速](/articles/shenxing-airport-review-2026) 或 [大佬云](/articles/dalaoyun-airport-review-2026)）；
2. 找到「快捷导入」模块，点击「一键导入 Shadowrocket」；
3. Safari 浏览器会自动弹窗提示“在 Shadowrocket 中打开”，点击允许，客户端即可自动解析并下载所有专线节点；
4. 若机场仅提供通用订阅链接，打开小火箭首页，点击右上角的 **「+」号**，类型（Type）选择 **「Subscribe」**，在 URL 处粘贴机场提供的订阅链接，备注填入服务商名称，点击右上角「完成」即可。

```
[小火箭订阅参数标准范式]:
URL: https://sub.your-airport-provider.com/api/v1/client/subscribe?token=xxxxxx
Type: Subscribe
Auto-Update: 开启 (打开应用时自动拉取最新节点)
```

### 2. 开启自动定时更新订阅
很多机场在遭遇机房割接或光缆维护时会动态发布新节点，若客户端未更新将显示全部超时：
* 点击小火箭右下角「设置」->「订阅」；
* 勾选 **「打开时更新」** 与 **「自动更新」**；
* 这样每次启动小火箭时，软件都会在后台毫秒级同步最新的专线入口。

## 四、 核心分流规则集优化（告别全局模式）

这是使用小火箭最关键的技术核心。许多用户抱怨“翻墙后国内淘宝打不开、微信发图片慢、网银被风控”，根源都在于使用了粗暴的“全局代理”。

### 1. 什么是全局路由的四大模式？
在小火箭主界面中间，可以明确看到「全局路由」选项：
* **配置 (Config - 强烈推荐)**：系统会逐条比对规则文件，属于境外的流量走节点加速，国内网站（百度、B站、淘宝）与国内 IP 自动走本地运营商直连，互不干扰；
* **代理 (Proxy - 严禁日常使用)**：所有流量一律强制走境外代理，耗费大量专线流量，且极易触发国内银行反洗钱风控；
* **直连 (Direct)**：所有流量不经过代理直接访问；
* **场景 (Scene)**：根据连接的不同 WiFi 自动切换分流策略。

### 2. 安装 ACL4SSR 高性能精简规则集
小火箭自带的默认规则较为陈旧，建议替换为业内广受好评的精简版规则：
1. 点击小火箭底部菜单栏的 **「配置」**；
2. 点击右上角 **「+」号**，在 URL 栏输入优质远程规则链接（例如：`https://raw.githubusercontent.com/ACL4SSR/ACL4SSR/master/Clash/config/ACL4SSR_Mini.ini`）；
3. 点击下载后，在规则列表中选中刚添加的规则文件，轻触并点击 **「使用配置」**；
4. 此时小火箭将具备精准的广告过滤、国内直连保护与主流 AI 大模型（ChatGPT / Claude）智能分流能力。

## 五、 高阶调优：按需连接（On Demand）与耗电发热控制

### 1. 按需连接（On Demand）彻底解决断流掉线
iOS 系统对后台常驻进程有着极为严苛的内存回收机制，当手机锁屏一段时间后，普通的 VPN 进程极易被系统休眠终止：
1. 打开小火箭「配置」页面，点击当前正在使用的规则右侧的 **「i」信息图标**；
2. 找到 **「按需连接（On Demand）」** 选项并将其开启；
3. 规则设置为“在蜂窝网络与未知 WiFi 下自动连接，在信任的家庭网络中保持策略”；
4. 开启后，手机状态栏的 VPN 标志将转为系统级守护，彻底告别微信消息延迟与后台断网。

### 2. 降低后台电量消耗实用技巧
* **关闭无意义的 HTTPS 解密**：在「设置」->「证书」中，若无特殊的去广告破解需求，切勿开启本地根证书解密，避免 CPU 长时间高负荷运算；
* **日志级别设置为 Error**：在「设置」中将日志等级由 Debug 改为 Error，大幅减少闪存读写并减轻发热。

## 七、 高频常见问题与技术排坑解答 (FAQ)

### Q1: 在国内 App Store 为什么搜索不到 Shadowrocket（小火箭）？
Shadowrocket 因政策合规原因未在中国大陆区 App Store 上架。用户需准备一个海外地区（推荐美区或港区）的 Apple ID，登录 App Store 后搜索并购买下载（官方正版售价为 2.99 美元，请认准开发者为 Shadow Launch Technology Limited）。

### Q2: 小火箭全局路由应该选择“配置”还是“代理”模式？
强烈建议必须选择“配置（Config）”模式。配置模式会根据规则文件自动识别境内外流量，国内应用直连、国外服务走代理；若选“代理（Proxy）”即为全局代理，不仅导致国内应用卡顿，还会耗尽专线流量并触发国内银行风控。

### Q3: 开启小火箭后手机发热严重、耗电极快怎么解决？
常见原因为规则集中包含了过量无效的广告拦截重写规则，或开启了过多的本地日志审计。建议在设置中关闭“HTTP 解密（HTTPS 证书解密）”，将日志记录级别调整为“错误”，并精简远程规则订阅。

### Q4: 节点显示连通且延迟为绿色，但打开推特或 YouTube 提示无网络连接？
首先检查 iOS 系统时间是否与当前北京时间偏差超过 60 秒（TLS 握手强校验时间）；其次进入小火箭「设置」->「DNS」，将主 DNS 修改为阿里公共 DNS（223.5.5.5）或腾讯 DNSPod（119.29.29.29），清除本地 DNS 缓存后重试。

### Q5: 什么是小火箭的“按需连接（On Demand）”功能？
按需连接是 iOS 系统的特权网络机制。开启后，小火箭会在检测到网络变化、切换 WiFi 或访问特定域名时自动在后台唤醒 VPN 通道，彻底避免锁屏后代理进程被 iOS 内存管理机制杀后台导致断连。
